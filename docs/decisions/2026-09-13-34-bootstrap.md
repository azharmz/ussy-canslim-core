# #34 Theory-Faithful Candidate Generator — Bootstrap Boundary

Date: 2026-09-13
Status: **IMPLEMENTATION STARTED / CONTRACT-FIRST**

## Upstream authority

#34 consumes `oneil-pattern-output-v2` from `azharmz/ussy-oneil-patterns`, engine `33-core-p8-frozen-v1`.

Only the four frozen core families enter this first #34 path:

- `FLAT_BASE`
- `DOUBLE_BOTTOM`
- `CUP_WITHOUT_HANDLE`
- `CUP_WITH_HANDLE`

P6 advanced families are excluded. Their failed independent morphology recognition validation must not be bypassed in #34.

## Non-negotiable boundary

#34 must not reconstruct or retune morphology. It must preserve canonical #33 identity, state, candidate semantics, detector faults, and provenance.

`AMBIGUOUS` and `REJECTED` #33 records remain evidence but cannot be promoted to `BASE_RECOGNIZED` by #34.

The parent repository's older local #33 detector is superseded and must not be called as a fallback.

## Stage order

The frozen #32 stage vocabulary is retained:

```text
BASE_RECOGNIZED
PIVOT_DEFINED
PIVOT_CROSSED
BREAKOUT_CONFIRMED
CANSLIM_ELIGIBLE
NOT_ELIGIBLE
NOT_EVALUABLE
```

A pivot cross is a price event and does not require the daily close to remain above the pivot. Close/hold quality is separate evidence.

Breakout volume uses the prior 50 completed sessions only. The evaluated breakout bar is excluded from its own baseline. `volume_ratio >= 1.40` is `CONFIRMED_ON_BREAKOUT`.

The initial minimum `CANSLIM_ELIGIBLE` composite remains:

```text
BREAKOUT_CONFIRMED
AND C_screen_state == PASS
AND A_screen_state == PASS
AND L_individual_leadership_state in {PASS, STRONG}
AND M_entry_state == ALLOW_NEW_BUYS
```

S/I/industry/N-catalyst remain evidence layers unless a separately versioned upstream contract promotes them.

## First implementation slice

`src/canslim_research/candidate_generator.py` is a deliberately small deterministic consumer that:

1. rejects noncanonical pattern-engine versions;
2. excludes non-core pattern families;
3. preserves #33 pattern state and faults;
4. computes pivot-cross/open/gap/close/extension facts;
5. computes the prior-50 volume ratio without lookahead;
6. advances explicit candidate stages without collapsing them into one Boolean;
7. only reaches `CANSLIM_ELIGIBLE` when the frozen minimum C/A/L/M states are present.

This bootstrap is not yet a historical universe runner. Data adapters for canonical #33 output, PIT fundamentals, RS/leadership and market state remain subsequent #34 work and must be versioned before #35 validation.
