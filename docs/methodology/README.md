# CAN SLIM Methodology Index

This directory stores interpretation rules, not raw SEC extraction logic.

| Letter | Meaning | Current research status |
|---|---|---|
| C | Current Quarterly Earnings | Data ready; methodology working spec exists; freeze next |
| A | Annual Earnings Growth | Data ready; methodology working spec exists; freeze after C |
| N | New | Legacy has breakout/new-high aspects; fundamental catalyst layer not implemented |
| S | Supply and Demand | Legacy has volume confirmation; float/shares extension pending |
| L | Leader or Laggard | Legacy RS vs market/sector is strong and already implemented |
| I | Institutional Sponsorship | Not implemented; deferred |
| M | Market Direction | Legacy SPY market regime is a hard gate |

The legacy technical framework is intentionally not called a literal O'Neil implementation. Research should preserve the distinction between O'Neil-derived concepts and our quantitative adaptations.
